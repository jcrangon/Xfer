# CARTE B - ARBITRAGE DE PERIMETRE (S3)

La direction fictive déclare : « Je veux les quatorze fonctionnalités dans six mois pour
75 000 €, même l'application native et le paiement. »

Cette intervention est une **demande d'arbitrage**, pas une nouvelle preuve de faisabilité.
Le groupe doit montrer trois périmètres cohérents, les dépendances, les exclusions,
les risques, et écrire quels engagements sont impossibles sans étude J3.
